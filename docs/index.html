Mars Rover installieren

Linienfolgender Zahnbürsten-Roboter auf ESP32 — Firmware direkt aus dem Browser auf das Gerät schreiben. Keine Entwicklungsumgebung nötig.

Dieser Browser kann nicht flashen.

Es wird Chrome, Edge oder Opera auf einem Rechner gebraucht. Firefox und Safari unterstützen die serielle Schnittstelle nicht, Handys ebenfalls nicht — weder Android noch iOS.

Die Seite muss über https:// geladen werden.
Diese Firmware lief noch nie auf echter Hardware. Sie kompiliert, mehr ist bislang nicht geprüft. Wer sie aufspielt, ist der erste.

Was gebraucht wird

  • Ein Rechner mit Chrome, Edge oder Opera — Handys können das nicht
  • Ein USB-Datenkabel (viele Ladekabel haben keine Datenadern)
  • Der Roboter bzw. ein ESP32-DevKit, über USB angesteckt

So geht es

  1. Gerät per USB anstecken
  2. Oben auf Mars Rover installieren klicken
  3. Im Auswahlfenster den seriellen Anschluss des Geräts wählen (meist CP210x oder CH340)
  4. Install One-of-a-Kind Mars Rover bestätigen und warten — etwa eine Minute
Erscheint kein Anschluss zur Auswahl, fehlt der USB-Seriell-Treiber. Für Boards mit CP2102 gibt es ihn bei Silicon Labs, für CH340 bei WCH. Windows installiert beide meist von selbst. Hilft das nicht: Kabel tauschen — das ist die häufigste Ursache.

Nach der Installation

  1. Gerät einschalten
  2. Am Handy ins WLAN MarsRover_…, Passwort marsrover
  3. Die Bedienseite öffnet sich meist von selbst. Falls nicht: http://192.168.4.1 im Browser aufrufen

Die Bedienoberfläche läuft im Gegensatz zu dieser Installationsseite auf jedem Handy — iPhone wie Android, ohne App.
